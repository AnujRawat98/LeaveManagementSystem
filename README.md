# Leave Management System

A Salesforce-based mini project for managing employee leave requests, leave balances, and leave history.

## Features

- Employee leave application
- Leave balance tracking
- Leave history
- Pending, Approved, and Rejected leave statuses
- Leave request validation
- Manager comments
- Automatic leave balance updates

## Technologies Used

- Salesforce
- Lightning Web Components (LWC)
- Apex
- SOQL
- Apex Triggers
- Apex Test Classes
- Custom Objects
- Lookup Relationships
- Validation Rules
- Formula Fields

## Salesforce Components

### Custom Objects

- Employee__c
- Leave_Request__c

### Apex

- Apex Classes
- Apex Trigger
- Apex Test Class

### Lightning Web Components

- Leave Dashboard
- Apply Leave
- Leave History

## Project Workflow

1. Employee submits a leave request.
2. The leave request is stored in Salesforce.
3. The request can be Pending, Approved, or Rejected.
4. Leave balance is updated based on the request status.
5. Employees can view their leave history.

## Learning Outcomes

This project helped me gain practical experience with Salesforce development, Apex, SOQL, triggers, LWC, data relationships, validation rules, and test classes.
